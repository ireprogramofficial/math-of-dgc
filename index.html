Working session

The math of DGC

Dynamics, control, and trajectory optimization, with one running example: planning an open-loop schedule for a boat on a river.

Definition

A dynamical system

A dynamical system is a pair \((X, f)\):

State space
\(X \subseteq \mathbb{R}^n\)
Dynamics
\(\dot{x} = f(x)\), where \(f : X \to \mathbb{R}^n\) is a vector field called the drift1

1 \(f\) is required to be locally Lipschitz, which guarantees a unique solution from each \(x_0\).

Trajectory
\(x(t) = \varphi_t(x_0)\): the state at time \(t\) from initial state \(x_0 \in X\), exactly one
Definition

A control system

A control system is a dynamical system \((X, f)\) with a control \((U, G)\) added:

Control space
\(U \subseteq \mathbb{R}^m\), with control schedules \(\mathcal{U} = \{\,u : [0,T] \to U\,\}\)
Dynamics
\(\dot{x} = f(x) + G(x)\,u(t)\), where \(G : X \to \mathbb{R}^{n \times m}\) is the input map
Trajectory
\(x(t) = \varphi_t(x_0, u)\), one for each \(u \in \mathcal{U}\)
Open-loop control

A control schedule

$$\dot{x} \;=\; f(x) \;+\; G\,u$$
  • State \(x=(p,v)\in\mathbb{R}^4\): position and velocity of the boat.
  • Drift \(f(x)=\big(v,\,-c\,(v-w(p))\big)\): what the river does with no control. \(w(p)\) is the water velocity .
  • Input \(u=(u_N,u_E,u_S,u_W)\in[0,1]^4\): four thrusters, none can pull backward.
  • Control matrix \(G\): constant here. Thrust adds acceleration \(G u\) .
  • Open loop: \(u\) depends on time only, fixed in advance. It never looks at \(x\).

Switch off a thruster and notice how the boat's reach changes.

Part 2 · Trajectory optimization

Find the best schedule, not just a schedule

$$\min_{u(\cdot)}\;\; \underbrace{\tfrac12\|x(T)-x^\star\|_Q^2}_{\text{terminal cost}} + \underbrace{\int_0^T \tfrac{\rho}{2}\|u\|^2\,dt}_{\text{effort}}$$ $$\text{s.t.}\quad \dot x = f(x)+Gu,\;\; x(0)=x_0,\;\; 0\le u\le 1$$
  • Decision: the whole schedule \(u(t)\), at once.
  • Objective: arrive near \(x^\star\) (target) at time \(T\) while spending little thrust.
  • Constraints: the dynamics, a fixed start, and non-negative bounded thrust. Staying off the banks is a soft penalty.
  • Deterministic: no noise, so the plan is exact and needs no feedback.

The dotted line is where the river alone would carry the boat.
