The math of DGC

Data-Guided Control

Dynamics, control, and trajectory optimization, with one running example: planning an open-loop schedule for a boat on a river.

Definition

A dynamical system

A dynamical system is a pair \((X, f)\):

State space
\(X \subseteq \mathbb{R}^n\)
Dynamics
\(\dot{x} = f(x)\), where \(f : X \to \mathbb{R}^n\) is a vector field (the drift, once we add control)
Trajectory
\(x(t) = \varphi_t(x_0)\): the solution of \(\dot{x} = f(x)\) with \(x(0) = x_0\)
(unique when \(f\) is smooth)
Definition

A control system

A control system is a dynamical system \((X, f)\) with a control \((U, G)\) added:

Control space
\(U \subseteq \mathbb{R}^m\)
Control schedule
\(u \in \mathcal{U} = \{\,u : [0,T] \to U\,\}\)
Dynamics
\(\dot{x} = f(x) + G(x)\,u(t)\),
where \(G : X \to \mathbb{R}^{n \times m}\) is the input map
Trajectory
\(x(t) = \varphi_t(x_0, u)\): the solution of \(\dot{x} = f(x) + G(x)\,u(t)\) with \(x(0) = x_0\); one for each \(u \in \mathcal{U}\)

For the boat: its velocity is the water's velocity plus the thrust's.

Key distinction

Open- versus closed-loop

Open loop
\(u(t)\)
\(\dot{x} = f(x) + G(x)\,u\)
gust
\(x\)
\(u\) is fixed in advance
Closed loop
\(u = \kappa(t, x)\)
\(\dot{x} = f(x) + G(x)\,u\)
gust
\(x\)
\(u\) reacts to \(x\)

The DGC algorithm is open loop.We can't measure a cell's state and adjust doses as we go.

Definition

Trajectory optimization

A trajectory optimization problem is an optimization problem on a control system:

1. State space
\(X \subseteq \mathbb{R}^n\)
2. Control space
\(U \subseteq \mathbb{R}^m\) (boat: \([0,1]^4\))
Decision space
\(u \in \mathcal{U} = \{\,u : [0,T] \to U\,\}\)
in practice: piecewise constant over \(K\) intervals, \(K \times m\) numbers
3. Objective
\(\min_{u \in \mathcal{U}} \|x(T) - x_{\text{target}}\|\),
horizon \(T\) fixed
4. Dynamics
\(\dot{x} = f(x) + G(x)\,u(t)\)
5. Constraints
\(x(0) = x_0\),
\(x(t) \in X\)

The solver also adds a small effort term, and enforces \(x(t) \in X\) with a penalty.

Key challenge

Unknown drift?

A dynamical system is a pair \((X, f)\):

State space
\(X \subseteq \mathbb{R}^n\)
Dynamics
\(\dot{x} = f(x)\), where \(f : X \to \mathbb{R}^n\) is the drift, unknown
Data
Initial basin: a time series \(x(t_0), x(t_1), \dots\)
Target basin: a single sample

In cell reprogramming we only get glimpses of how the system behaves naturally.

Key challenge

Optimal control?

Plan with a fitted drift \(\hat{f}\):

$$\min_{u \in \mathcal{U}}\ \|x(T) - x_{\text{target}}\| \quad \text{s.t.}\quad \dot{x} = \hat{f}(x) + G(x)\,u$$
Start
\(x(0) = x(t_0)\), the first sample in the initial basin
Target
\(x_{\text{target}}\), the single sample in the target basin
Constraints
\(x(t) \in X\)
Then
run the same \(u\) on the actual drift:
\(\dot{x} = f(x) + G(x)\,u\)

An optimal plan is only as good as the drift it was planned on.
