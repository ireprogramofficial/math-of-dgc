The math of DGC

Dynamics, control, and trajectory optimization, with one running example: planning an open-loop schedule for a boat on a river.

Definition

A dynamical system

A dynamical system is a pair \((X, f)\):

State space
\(X \subseteq \mathbb{R}^n\)
Dynamics
\(\dot{x} = f(x)\), where \(f : X \to \mathbb{R}^n\) is a vector field called the drift
Trajectory
\(x(t) = \varphi_t(x_0)\): the state at time \(t\) from initial state \(x_0 \in X\), exactly one
Definition

A control system

A control system is a dynamical system \((X, f)\) with a control \((U, G)\) added:

Control space
\(U \subseteq \mathbb{R}^m\)
Control schedule
\(u \in \mathcal{U} = \{\,u : [0,T] \to U\,\}\)
Dynamics
\(\dot{x} = f(x) + G(x)\,u(t)\),
where \(G : X \to \mathbb{R}^{n \times m}\) is the input map
Trajectory
\(x(t) = \varphi_t(x_0, u)\),
one for each \(u \in \mathcal{U}\)

Drift dynamics and thrust dynamics together make the system's full dynamics.

Key distinction

Closed- versus open-loop

Open loop
\(u(t)\)
\(\dot{x} = f(x) + G(x)\,u\)
\(x\)
\(u\) is fixed in advance
Closed loop
\(u = \kappa(x)\)
\(\dot{x} = f(x) + G(x)\,u\)
\(x\)
\(u\) reacts to \(x\)

The DGC algorithm is open loop.

Definition

Trajectory optimization

A trajectory optimization problem is an optimization problem on a control system:

1. State space
\(X \subseteq \mathbb{R}^n\)
2. Control space
(decision space)
\(U \subseteq \mathbb{R}^m\),
\(u \in \mathcal{U} = \{\,u : [0,T] \to U\,\}\)
3. Objective
\(\|x(T) - x_{\text{target}}\|\)
4. Dynamics
\(\dot{x} = f(x) + G(x)\,u(t)\)
5. Constraints
\(x(0) = x_0\),
\(0 \le u(t) \le 1\)
